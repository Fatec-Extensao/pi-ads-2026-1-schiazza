## Visão Geral do Projeto

**Etapa:** Etapa 2 — Fase de Prototipação, Estruturação de Interface Web e Modelagem de Dados

**Título:** Sistema Web para Gestão de Pesquisas por Questionários

**Temática:** Desenvolvimento de interfaces web e projeto de banco de dados voltados ao atendimento de demandas reais.

**Carga Horária:** 30 horas/aula semestrais

**Público-alvo:** Instituições que necessitem realizar pesquisas institucionais por meio da aplicação de questionários.

### Descrição

O projeto tem como objetivo proporcionar uma experiência prática de desenvolvimento de software, integrando conhecimentos das disciplinas do semestre.

A solução deverá contemplar análise de requisitos, modelagem de dados, desenvolvimento de interfaces web, princípios de usabilidade, segurança da informação e geração de informações analíticas.

O sistema será desenvolvido para permitir a criação, aplicação e análise de pesquisas institucionais por meio de questionários, garantindo a organização das respostas e o anonimato dos participantes quando aplicável.

---

## Objetivos

O projeto tem como objetivo desenvolver um Sistema Web para Gestão de Pesquisas por Questionários, permitindo:

* cadastrar e gerenciar pesquisas;
* definir categorias de participantes;
* criar questionários específicos para cada categoria;
* disponibilizar acesso anônimo às pesquisas;
* coletar e armazenar respostas;
* acompanhar a participação dos respondentes;
* gerar relatórios estatísticos e analíticos;
* implementar novas funcionalidades definidas pela equipe durante a evolução do projeto.

---

## Competências Desenvolvidas

### Desenvolvimento Web

Desenvolvimento de interfaces utilizando tecnologias web, com foco em HTML, CSS e JavaScript, aplicando princípios de organização, acessibilidade e usabilidade.

### Banco de Dados I

Elaboração dos modelos conceitual, lógico e físico do banco de dados de acordo com as regras de negócio identificadas no projeto.

### Engenharia de Software II

Modelagem e documentação do sistema utilizando técnicas de Engenharia de Software e diagramas baseados em UML.

### Compliance e Segurança da Informação

Aplicação de conceitos relacionados à segurança da informação, privacidade, proteção de dados e conformidade com a Lei Geral de Proteção de Dados — LGPD.

---

## Etapas de Desenvolvimento

1. Levantamento e análise dos requisitos.
2. Definição da identidade visual e arquitetura da informação.
3. Desenvolvimento das interfaces da aplicação.
4. Modelagem do banco de dados.
5. Elaboração da documentação técnica.
6. Análise de riscos e requisitos de segurança.
7. Avaliação da conformidade com a LGPD.
8. Integração dos artefatos produzidos pelas disciplinas.
9. Validação e apresentação da solução.
